2. AI 分析主流程（SSE Flow）

从前端发起到 token 流式返回的完整路径。

flowchart TD
    A[前端调用 GET /api/ai-analysis/stream] --> B[AiAnalysisController 创建 SseEmitter]
    B --> B1[SSE 超时 120000ms]
    B1 --> C[CompletableFuture 异步调用 AiAnalysisService.streamAnalysis]
    C --> D{是否配置 deepseek.api-key}
    D -- 否 --> E[发送 ai-error: 未配置 API Key]
    E --> F[emitter.complete]
    D -- 是 --> G[portfolioService.requirePortfolioId]
    G --> H[portfolioItemRepository.findAll 获取持仓]
    H --> I[assetCatalogRepository.findAllWithLatestPrice 获取行情]
    I --> J[buildRequestBody 构造系统提示词和用户数据]
    J --> K[HttpClient POST DeepSeek /chat/completions]
    K --> K1[参数 stream=true, temperature=0.2, max_tokens=700]
    K1 --> K2[connectTimeout=10s, requestTimeout=90s]
    K2 --> L{HTTP 状态是否 200}
    L -- 否 --> M[发送 ai-error: DeepSeek 调用失败]
    M --> F
    L -- 是 --> N[逐行读取 SSE data]
    N --> O{data == [DONE]?}
    O -- 否 --> P[readContentToken 提取 delta.content]
    P --> Q{token 是否为空}
    Q -- 否 --> R[发送 token 事件给前端]
    R --> N
    Q -- 是 --> N
    O -- 是 --> S[发送 complete: done]
    S --> F
    C -.异常.-> T[发送 ai-error: AI 分析暂时不可用]
    T --> F

3. 现金入账与汇率处理流程（Cash + FX Flow）

描述 DTO 字段兼容、币种规范化和汇率异常语义。

flowchart TD
    A[接收 CashDepositRequest JSON] --> B[解析 amount / portfolioId / currencyCode]
    B --> C[resolveCurrencyCode]
    C --> C1{currencyCode 有值?}
    C1 -- 是 --> D[使用 currencyCode]
    C1 -- 否 --> C2{currency 有值?}
    C2 -- 是 --> D1[使用 currency]
    C2 -- 否 --> C3{cashCurrency 有值?}
    C3 -- 是 --> D2[使用 cashCurrency]
    C3 -- 否 --> D3[默认 USD]
    D --> E[CashFxService.getUsdQuote]
    D1 --> E
    D2 --> E
    D3 --> E
    E --> F[normalizeCurrency: trim + uppercase]
    F --> G{是否在支持列表 USD/GBP/EUR/CNY/JPY/HKD}
    G -- 否 --> H[抛 400 BAD_REQUEST Unsupported currencyCode]
    G -- 是 --> I[FxRateApiClient.getToUsdRate]
    I --> J{调用成功?}
    J -- 否 --> K[抛 502 BAD_GATEWAY Unable to fetch exchange rate]
    J -- 是 --> L[返回 FxQuote(currencyCode, usdRate)]
